## 📖 Описание проекта

Этот проект представляет собой API для интернет-магазина продуктов с функционалом управления категориями, продуктами и
корзиной.
Реализованы эндпоинты для просмотра, добавления, редактирования и удаления данных, а также система авторизации по
токену.
---

## 🚀 Установка и настройка

1. **Клонируйте репозиторий:**

   ```bash
   git clone https://github.com/AndyTums/ProductShop.git
   ```

2. **Установите зависимости:**

   ```bash
   poetry update
   ```

3. **Настройте базу данных:**

   Убедитесь, что у вас установлен PostgreSQL и создана база данных. Создайте .env файл и внесите необходимы настройки
   согласно .env.example

   ```bash
   SECRET_KEY=

   DEBUG=
   
   NAME=
   HOST=
   USER=
   PASSWORD=
   PORT=
   ```

4. **Примените миграции::**

   ```bash
   python manage.py migrate
   ```

5. **Примените миграции с помощью созданной команды:**

   ```bash
   python manage.py csu
   ```

6. **Запустите сервер:**

   ```bash
   python manage.py runserver
   ```

## 🚀 Функционал

### Основные возможности

**Основные возможности:**

- Создание, редактирование, удаление категорий и подкатегорий через админку.
- Каждая категория/подкатегория имеет: наименование, slug-имя, изображение
- Эндпоинт для просмотра всех категорий с подкатегориями (с пагинацией).
- Подкатегории связаны с родительской категорией.
- CRUD перации для всех моделей.
- API корзины только активным пользователям.
- Аутентификация пользователей по токенам.

## 🔌 API

### Основные эндпоинты

| Метод  | URL                    | Описание                 | Аутентификация |
|--------|------------------------|--------------------------|----------------|
| `CRUD` | `/user/`               | Модель пользователя      | Не Требуется   |
| `CRUD` | `/shop/categories/`    | Модель категорий         | Не Требуется   |
| `CRUD` | `/shop/subcategories/` | Модель подкатегорий      | Не Требуется   |
| `CRUD` | `/cart/`               | Модель корзины           | ✅ Требуется    |
| `CRUD` | `/cart/items/`         | Модель товаров в корзине | ✅ Требуется    |
| `POST` | `/cart/items/clear/`   | Эндп. очистки корзины    | ✅ Требуется    |
| `POST` | `/login/`              | Авторизация              |                | 
| `POST` | `/token/refresh/`      | Обновление токена        |                | 


## 🖥 Админ-панель

**В админ-панели вы можете:**

- Просматривать и редактировать созданные объекты категории, подкатегории, товаров в корзине и пользователей.
- Фильтровать объекты по категориям, подкатегориям, пользователям.
